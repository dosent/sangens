# Правила работы над проектом Sangens

## Язык проекта

- Вести проект на русском языке: документацию, планы, комментарии и пояснения в коде, сообщения коммитов, описания изменений и автоматических проверок.
- Интерфейс, подсказки, ошибки и сообщения интеграции и карточки писать на русском. Дополнительные языки добавлять только по запросу владельца.
- Сохранять стандартные программные имена Home Assistant, поля и значения протокола Sangens, имена зависимостей, форматы и обязательные названия файлов. Идентификаторы в коде должны оставаться совместимыми с экосистемой.
- Не переводить и не заменять исходный текст лицензии MIT и правовые уведомления сторонних компонентов.

## Работа с изменениями

- Работать по согласованной спецификации и плану в `docs/superpowers/`.
- Сохранять проверенные законченные части отдельными коммитами с понятными русскими сообщениями.
- Не включать в репозиторий токены, пароли, PIN, серийные номера, личные данные и оригинальные медиафайлы приложения Sangens.
- Настройка Sangens общая для всех пользователей HA; учётные данные хранятся только на сервере.
- При разработке не отправлять настоящей печи команды нагрева. Проверять команды на имитации API, а подключение начинать с чтения показаний.
