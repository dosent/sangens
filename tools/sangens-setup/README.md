# Разовая проверка Sangens на Mac

Неофициальный помощник для подключения печи к общей записи Home Assistant. Воспроизводит механизм WebView предоставленного приложения: настоящий Google reCAPTCHA, локальный HTML и baseURL API Sangens. Автоматического решения CAPTCHA, чтения установленного приложения и поддельного результата нет. Владелец подтвердил успешный вход с этим помощником 27 октября 2026 года; последующее чтение устройства из HA вернуло HTTP 200.

1. В HA начните добавление «Печь Sangens → Вход по почте и коду» и сами введите почту.
2. Если появился шаг «Проверка Sangens», откройте собранный `Sangens Setup.app` на Mac.
3. Нажмите «Пройти проверку». Если Google покажет задание, выполните его самостоятельно.
4. Нажмите «Скопировать результат» и сразу вставьте его в поле HA «Результат проверки reCAPTCHA». Подтвердите в HA в течение 110 секунд.
5. Если Sangens принял проверку, введите код из письма в следующей форме HA. Затем выберите печь. Начните с чтения показаний.

Настройка общая для всех пользователей. Помощник нужен только при первичном или повторном входе, если сервис требует CAPTCHA; постоянно запускать его не нужно. Почта, код и облачная сессия через помощник не проходят. Результат Google не отправляйте в чат. В память буфера обмена он попадает только кнопкой; помощник удалит свою запись по истечении срока или закрытии, если буфер ещё не заменён вами. Не закрывайте помощник до вставки в HA.

Проверка выполняется в обычном WKWebView с проверкой сертификатов. Cookies не сохраняются между запусками. Не отключайте защиту macOS для запуска. При отказе Google или Sangens остановитесь и сохраните только текст ошибки без самого результата. Два неудачных запроса с результатом проверки приостанавливают вход минимум на пять минут; автоматических повторов нет.

## Сборка

Нужны macOS 13+ и установленный Swift из Xcode Command Line Tools. Из корня репозитория:

```sh
python3 tools/sangens-setup/build.py /абсолютный/путь/для/сборки
swiftc -module-cache-path .swift-module-cache tools/sangens-setup/VerificationState.swift tools/sangens-setup/state-tests.swift -o /tmp/sangens-state-tests
/tmp/sangens-state-tests
npm test
```

Приложение собирается для архитектуры текущего Mac, без сторонних пакетов и подписи разработчика. Исходники доступны здесь; готовый локальный пакет не публикуется автоматически в GitHub. Открыть сборку и нажать проверку должен человек.
