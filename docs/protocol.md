# Протокол Sangens: восстановленные данные

Источник — предоставленный владельцем APK React Native/Hermes и декомпиляция. Протокол восстановлен по коду приложения, но пока не подтверждён авторизованным ответом действующего сервиса. Адрес: `https://api.sangens.com/api`.

## Вход

Приложение отправляет `POST /email/send` с `email` и `recaptcha`, получает `data.emailToken`; проверяет код через `POST /email/check`, затем выполняет `POST /auth/loginByEmail` с `token` и `code`. Итог — `data.token`, используемый как `Authorization: Bearer …`. Внешний ответ обёрнут в `data`.

`refreshToken` в найденном компоненте относится к обновлению CAPTCHA, а не облачного токена. Подтверждённого API продления авторизации нет.

CAPTCHA выполняется в WebView приложения с базовым адресом Sangens. В браузере HA другой источник: перенос этого кода с подменой источника или отключением проверки не является поддерживаемым входом. Публичный корень сервиса ведёт на административный вход, который не подходит пользователю приложения. Поэтому автоматическая авторизация по почте в HA пока не реализуема на подтверждённом контракте. Требуется разрешённый производителем пользовательский способ входа или выданный владельцу токен доступа. Токены из приложения и браузера не извлекаются.

До решения этого ограничения установка на действующий сервер и обещание работающего облачного подключения блокируются. Независимые клиент, сущности и карточка могут проверяться с явно искусственными ответами. Подключение через токен, если оно будет предоставлено администратором легитимным способом, должно проверять его на сервере и хранить только в записи HA.

## Запросы

| Операция | Запрос | Тело |
| --- | --- | --- |
| Устройства | GET `/microchip-user` | — |
| Состояние | GET `/microchip-user/{binding_id}` | — |
| Питание | POST `/microchips/{microchip_id}/set-remote-control-status` | `remoteControlStatus`: `ON` или `off` |
| Воздух | POST `/microchips/{microchip_id}/set-air-temperature` | `setAirTemperature` |
| Камни | POST `/microchips/{microchip_id}/set-target-stone-temperature` | `targetStoneTemperature` |
| Режим | POST `/microchip-user/{binding_id}/set-mode` | `modeId` |

В `DeviceService` список извлекается как `response.data.data` и десериализуется фабрикой моделей. Точную форму списка и сведения о пагинации требуется сверить на действующем аккаунте, прежде чем считать совместимость подтверждённой.

`binding_id` — идентификатор пользовательской привязки; `microchip_id` — идентификатор контроллера в `microchip.id`. Они не взаимозаменяемы. Команда питания не должна использовать переключение: точные значения чувствительны к регистру.

## Показания

`microchip.connectionStatus`: `online` / `offline`. `microchip.data.remoteControlStatus`: `ON` / `off`. Температуры: `currentAirTemperature`, `setAirTemperature`, `firstStoneTemperature`, `secondStoneTemperature`, `targetStoneTemperature`. Нагреватели: `airHeaterStatus`, `firstStoneHeaterStatus`, `secondStoneHeaterStatus`; допустимые значения этих признаков ещё требуют проверки. Неизвестный формат не считается выключением.

Режимы: `mode`, `defaultMode`; ограничения в данных режима: `minAirTemp`, `maxAirTemp`, `minHeaterTemp`, `maxHeaterTemp`. Подробную вложенность необходимо проверить. Нельзя брать диапазоны со шкалы экрана в качестве допустимых границ команд.

Ответ 409 обозначает ожидание другой команды (`WAIT_ACTION_ERROR_CODE` в приложении). Не выполнять автоматический повтор управляющего запроса. Тайм-аут означает неизвестный результат, а не гарантированный отказ.

## Уровень проверки

- Чтение APK: выполнено.
- Совпадение с работающим аккаунтом: не проверено.
- Авторизация из HA: заблокирована неподтверждённым пользовательским входом и CAPTCHA.
- Команды реальной печи: не выполнялись.
